# 지면을 고르는 기준

## 먼저 배치를 결정한다

인쇄용은 지면·자료 상자·표·답란의 배경을 모두 흰색으로 한다. 아래 스타일의 종이색·어두운 면·파스텔 배경은 인쇄용에서 생략한다. 포인트 색은 글자, 기능이 있는 선, 의미 있는 그림에만 사용한다.

| 지면 구성 | 작업 공간의 관계 | 적합성을 확인할 것 |
|---|---|---|
| 기본형 · 순서형 | 자료 다음에 번호가 있는 문항과 답란을 순서대로 | 별도 이동 없이 읽고 쓸 수 있고 응답 길이에 맞는 공간이 있는가 |
| 기본형 · 기록표형 | 짧은 활동 항목과 질문·긴 응답 칸을 한 표에 배치 | 표의 구분이 유용하며 긴 응답을 작은 칸에 가두지 않는가 |
| 잡지형 | 좁은 자료 열과 넓은 발문·응답 열을 나란히 | 원자료를 오가며 읽기 쉽고 긴 응답 폭이 충분한가 |
| 탐구 지도형 | 중심 질문 주변에 기준·근거·걱정·결론을 배치 | 연결선·화살표가 실제 사고 관계를 표현하는가 |
| 작업 노트형 | 큰 스케치·계산 공간과 작은 메모, 마지막 정리 영역 | 작업을 진행하면서 생각을 덧붙일 여백이 충분한가 |
| 카드형 | 독립된 과제를 나란히 배치하거나 잘라 사용 | 한 카드 안에 자료·지시·필요한 기록 공간이 함께 있는가 |
| 신문형 | 여러 단의 원자료·인용·비교 기사와 응답 공간 | 읽는 순서와 자료별 질문이 명확한가 |
| 스토리보드형 | 장면·절차 순서에 따라 그림과 설명을 반복 | 순서 변화가 학습 과제에 필요한가 |

같은 내용을 비교하는 시안을 만들 때는 원자료와 학습 목표를 유지해 배치의 차이를 확인한다. 색·글꼴만 바꾼 예시는 별도 레이아웃으로 세지 않는다. 위 구성은 시작점이며 사용자 요청에 맞게 결합·변형한다.

## 제목부는 짧고 유용하게

- 기본형을 포함해 모든 활동지에서 제목부가 본문보다 시선을 독점하지 않도록 한다. 일반 A4 제목은 16~20pt 정도에서 시작해 글 길이와 대상에 맞게 조절한다.
- 제목은 가능하면 한 줄, 길면 자연스럽게 두 줄로 흐르게 한다. 포스터처럼 보이게 하려고 짧은 제목에 수동 줄바꿈을 넣지 않는다.
- 학년·반·번호·이름은 한 줄로 정돈하고 중복 선이나 빈 상자를 넣지 않는다. 안내는 실제 수행에 필요한 한두 문장만 둔다.
- 과목·단원 표기가 필요하면 작게 배치한다. 영문 디자인 이름이나 레이아웃 설명을 학생용 제목 위에 붙이지 않는다.
- 제목부와 본문 사이 여백을 실제 인쇄 크기로 확인한다. 예시는 제목부 자체를 대략 20~30mm 이내로 정리하되 고정 높이나 잘림으로 강제하지 않는다. 줄인 공간은 답란·스케치·계산·교사 메모 등에 활용한다.

스타일은 수업 목적이 아닌 시각적 특징으로 구분한다. 각 스타일은 여러 교과와 활동에 적용할 수 있다. 아래는 출발점이며 정해진 양식이 아니다.

| 디자인 스타일 | 시각적 특징 | 구성 판단 |
|---|---|---|
| Editorial | 큰 제목, 넓은 여백, 얇은 선, 절제된 포인트 색 | 자료와 발문의 위계를 크기와 간격으로 표현 |
| Notebook | 세리프 제목, 따뜻한 중성색, 점선과 기록선 | 실제로 쓰거나 그릴 공간을 충분히 확보 |
| Soft Grid | 옅은 색 면, 부드러운 모서리, 정렬된 여러 영역 | 구분이 필요할 때만 색 면을 쓰고 응답 영역의 역할을 명시 |
| Swiss Grid | 비대칭 그리드, 산세리프, 명확한 정렬과 크기 대비 | 읽는 순서와 자료의 관계를 정렬로 표현 |
| Monochrome | 한 색의 명도 차이, 선과 여백 | 강조가 색에만 의존하지 않고 출력에서도 구분 |
| Collage | 이미지·메모의 겹침, 다양한 크기와 질감 | 질문과 쓰는 공간을 가리지 않으면서 읽는 순서 확보 |
| Graph Paper | 정밀한 모눈, 짙은 축과 옅은 보조선, 간결한 숫자 | 식·완성 그래프·빈 좌표평면과 계산 공간을 연결 |
| Monochrome Ledger | 검정·회색, 큰 문자 표식, 나란한 열 | 색 없이도 비교 항목과 판단 공간이 구분되는가 |
| Playful Geometry | 큰 도형, 적은 수의 밝은 색, 둥근 표현 공간 | 그림이 활동의 대상이며 모양·라벨로도 구분되는가 |

두 방향을 섞어도 된다. 예를 들어 Notebook의 기록 공간에 Monochrome Ledger의 흑백 구성을 적용하거나, Graph Paper의 정확한 좌표평면을 Editorial 지면에 넣을 수 있다. 스타일을 늘릴 때는 새 이름보다 배치·시각 재료·글자 크기의 실제 차이를 먼저 만든다.

## 이름이 아니라 지면으로 구분하기

- 같은 제목·상자·표 배열에서 색만 바꾼 것을 별개의 스타일로 제시하지 않는다. 자료와 질문의 위치, 열의 비율, 제목의 크기, 선과 면의 사용에 실제 차이를 만든다.
- 교사의 목적에 필요한 시각 자료를 준비한다. 함수 문제에는 정확한 그래프, 관찰에는 대상 그림, 비교에는 관계가 드러나는 배치를 사용할 수 있다. 장식을 위한 빈 색 상자를 추가하지 않는다.
- 한글 제목과 본문은 자간·굵기·행간을 함께 조정한다. 필요한 경우 이용 조건을 확인한 글꼴을 HTML에 포함하고 고지를 보존한다. 예시에 쓰인 글꼴이나 색을 다른 요청의 의무로 삼지 않는다.
- 자료 읽기, 비교, 계산, 그림, 긴 서술에 같은 답란을 반복하지 않는다. 번호·발문·응답 공간이 이어지는지를 실제 크기로 확인한다.

색은 제목·자료 구분·중요한 관계에 사용한다. 흑백을 기본으로 강제하지 않는다. 페이지 위아래를 채우는 장식, 의미 없는 색 상자, 인적 사항 아래 중복 선은 피한다.

자료 상자나 제목의 위쪽·왼쪽에 장식용 강조선을 붙이지 않는다. 색·글자 크기·여백으로 구분하고 표 테두리, 그래프 축처럼 기능이 있는 선만 사용한다. 표의 제목·짧은 항목·숫자는 가운데 정렬을 검토하고, 긴 설명·서술 답란은 왼쪽 정렬로 읽기와 쓰기를 돕는다.

## 쓰는 공간부터 확인

- 한 줄 응답과 근거를 설명하는 응답에 같은 높이를 주지 않는다. 괘선은 손글씨 한 줄이 실제로 들어가는 간격에서 시작해 대상과 분량에 맞게 조절한다.
- 비교표의 첫 열은 분류 표식만 필요한 만큼 쓰고, 응답 열에 폭을 배분한다. 모든 표를 같은 폭·같은 행 높이로 만들 필요가 없다.
- 빈 칸이 막막할 때만 ‘어떤 자료를 봐야 하는가’, ‘무엇을 판단하는가’ 같은 도움 질문을 넣는다. 도움말도 인쇄에서 읽히는 크기와 명도를 갖춰야 한다.
- 그림·문구·근거를 함께 만드는 과제는 한 빈 상자보다 역할이 다른 영역이 유용할 수 있다. 반대로 자유 표현 과제는 지나치게 쪼개지 않는다.
- 문항과 그 답란을 함께 두고, 내용이 길면 자연스럽게 다음 쪽으로 흐르게 한다. 화면과 인쇄의 본문 폭을 맞추면 불필요한 줄바꿈 차이가 줄어든다.

## 참고 자료를 볼 때

겉모양보다 활동 번호의 계층, 발문과 답란의 거리, 응답 형식, 도움 질문, 피드백 뒤 수정 공간을 관찰한다. 여러 참고 자료의 장점을 목적에 맞게 조합한다. 특정 자료의 장식과 순서를 그대로 복제하거나, 한 사례의 치수를 모든 활동의 규칙으로 만들지 않는다.

## Additional reference directions

| Style | Visual grammar | Adaptation |
|---|---|---|
| Pin & Paper | Yellow paper, ink blue, loose memo placement | Use notes as real observation or response areas; omit ornamental pins and binder holes. |
| Cobalt Grid | Cobalt typography, precise grid, editorial hierarchy | Use actual mathematical grids and calculated coordinates; omit pixel ornaments and accent rules. |
| Grove | Forest green, cream, classical serif hierarchy | Keep worksheet writing areas light; mix dark and light presentation scenes. |
| Notebook Tabs | Paper page, coloured section tabs | Label actual sections; make screen tabs navigate when appropriate. |
| Retro Zine | Beige paper, saturated green, oversized print-like type | Vary source, headline and draft space; preserve readability and actual response space. |
| Sakura Chroma | Cream paper, retro multicolour palette, geometric motifs | Use colours to distinguish real categories; use an illustration only when it relates to content. |

These directions can be combined or replaced by a user reference. They are not a closed preset list, required palette or fixed layout. Centre short table labels and numerical entries where appropriate. Keep explanatory text left-aligned. Do not add decorative top or left accent rules.
