# 지면을 고르는 기준

스타일은 수업 목적이 아닌 시각적 특징으로 구분한다. 각 스타일은 여러 교과와 활동에 적용할 수 있다. 아래는 출발점이며 정해진 양식이 아니다.

| 디자인 스타일 | 시각적 특징 | 구성 판단 |
|---|---|---|
| Editorial | 큰 제목, 넓은 여백, 얇은 선, 절제된 포인트 색 | 자료와 발문의 위계를 크기와 간격으로 표현 |
| Notebook | 세리프 제목, 따뜻한 중성색, 점선과 기록선 | 실제로 쓰거나 그릴 공간을 충분히 확보 |
| Soft Grid | 옅은 색 면, 부드러운 모서리, 정렬된 여러 영역 | 구분이 필요할 때만 색 면을 쓰고 응답 영역의 역할을 명시 |
| Swiss Grid | 비대칭 그리드, 산세리프, 명확한 정렬과 크기 대비 | 읽는 순서와 자료의 관계를 정렬로 표현 |
| Monochrome | 한 색의 명도 차이, 선과 여백 | 강조가 색에만 의존하지 않고 출력에서도 구분 |
| Collage | 이미지·메모의 겹침, 다양한 크기와 질감 | 질문과 쓰는 공간을 가리지 않으면서 읽는 순서 확보 |

색은 제목·자료 구분·중요한 관계에 사용한다. 흑백을 기본으로 강제하지 않는다. 페이지 위아래를 채우는 장식, 의미 없는 색 상자, 인적 사항 아래 중복 선은 피한다.

## 쓰는 공간부터 확인

- 한 줄 응답과 근거를 설명하는 응답에 같은 높이를 주지 않는다. 괘선은 손글씨 한 줄이 실제로 들어가는 간격에서 시작해 대상과 분량에 맞게 조절한다.
- 비교표의 첫 열은 분류 표식만 필요한 만큼 쓰고, 응답 열에 폭을 배분한다. 모든 표를 같은 폭·같은 행 높이로 만들 필요가 없다.
- 빈 칸이 막막할 때만 ‘어떤 자료를 봐야 하는가’, ‘무엇을 판단하는가’ 같은 도움 질문을 넣는다. 도움말도 인쇄에서 읽히는 크기와 명도를 갖춰야 한다.
- 그림·문구·근거를 함께 만드는 과제는 한 빈 상자보다 역할이 다른 영역이 유용할 수 있다. 반대로 자유 표현 과제는 지나치게 쪼개지 않는다.
- 문항과 그 답란을 함께 두고, 내용이 길면 자연스럽게 다음 쪽으로 흐르게 한다. 화면과 인쇄의 본문 폭을 맞추면 불필요한 줄바꿈 차이가 줄어든다.

## 참고 자료를 볼 때

겉모양보다 활동 번호의 계층, 발문과 답란의 거리, 응답 형식, 도움 질문, 피드백 뒤 수정 공간을 관찰한다. 여러 참고 자료의 장점을 목적에 맞게 조합한다. 특정 자료의 장식과 순서를 그대로 복제하거나, 한 사례의 치수를 모든 활동의 규칙으로 만들지 않는다.
